# NeoNV v1.1.3

This patch improves typing responsiveness in long notes.

### Fixes

- **Faster editing in long notes** — typing and cursor movement avoid repeated document-wide completion searches and redundant text processing, including costly comparisons in notes containing emoji or other non-ASCII text.
- **Safer wiki-link completion** — completing an unfinished `[[target` keeps text on following lines intact, even when another wiki link appears later in the note.

### Installation

Install or upgrade with Homebrew:

```bash
brew upgrade --cask msnodderly/tap/neonv
```

Alternatively, download the DMG and drag NeoNV to Applications.

**First launch for a manually downloaded unsigned build:**
1. Double-click NeoNV — macOS blocks it
2. Open **System Settings → Privacy & Security**
3. Click **Open Anyway** in the Security section
4. Enter your password when prompted
