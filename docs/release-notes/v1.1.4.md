# NeoNV v1.1.4

New notes stay selected and ready for typing, and autosave preserves every character.

### Fixes

- **New notes are highlighted immediately** — creating a note from search or with Command-N keeps the new row selected and visible, with focus in its editor. Clearing the search no longer restores the previously selected note. Works in both sidebar and top-list layouts.
- **Complete autosaves during fast typing** — autosave receives every edit directly from the editor, so rapid typing no longer leaves the final character unsaved.

### Installation

Install or upgrade with Homebrew:

```bash
brew upgrade --cask msnodderly/tap/neonv
```

Alternatively, download the DMG and drag NeoNV to Applications.

**First launch for a manually downloaded unsigned build:**
1. Double-click NeoNV — macOS blocks it
2. Open **System Settings → Privacy & Security**
3. Click **Open Anyway** in the Security section
4. Enter your password when prompted
